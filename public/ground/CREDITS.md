# Ground textures

Scanned textures from [Poly Haven](https://polyhaven.com), released under
CC0 (public domain). Resized to 512 px and converted to WebP. The terrain
shader (`src/terrainMaterial.ts`) uses only their brightness and normals.

| File | Poly Haven asset |
|---|---|
| grass | [aerial_grass_rock](https://polyhaven.com/a/aerial_grass_rock) |
| dry | [dry_ground_rocks](https://polyhaven.com/a/dry_ground_rocks) |
| soil | [brown_mud_rocks_01](https://polyhaven.com/a/brown_mud_rocks_01) |
| sand | [aerial_sand](https://polyhaven.com/a/aerial_sand) |
| litter | [forest_leaves_02](https://polyhaven.com/a/forest_leaves_02) |
| moss | [mossy_rock](https://polyhaven.com/a/mossy_rock) |
| rock | [cliff_side](https://polyhaven.com/a/cliff_side) |
